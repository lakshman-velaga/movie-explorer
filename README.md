# Movie Explorer

A movie browsing app built with React and Vite.

🔗 **Live demo:** [movie-explorer-silk-five.vercel.app](https://movie-explorer-silk-five.vercel.app)

## Features
- Browse movies in a card layout
- Open a movie to see its details
- Responsive design for mobile and desktop

## Tech Used
React, Vite, JavaScript, CSS3

## Run it locally
```bash
npm install
npm run dev
```

## What I learned
- Building a React app with reusable components
- Managing state and passing props
- Deploying with Git, GitHub and Vercel
